# Calibration Starter — AURORA GRID OS v2.2.0

**Purpose:** Begin the prospective scored-forecast track required for empirical validation.

## Minimum record for each scored forecast

Every entry must capture before resolution:

- pre-resolution wording
- timestamp (UTC)
- probability (5-point increments)
- range / horizon
- resolution criteria
- resolution source (planned)
- reference class
- gate state
- binding constraint
- trigger
- falsifier
- action state
- framework_version (`2.2.0`)

After resolution, add:

- outcome (`RES-HIT` / `RES-PARTIAL` / `RES-MISS` / `RES-VOID`)
- resolution source and timestamp
- notes on reasoning quality vs outcome

## Target

Produce and lock **10–20** prospectively resolved forecasts with full RECORD LOCK trails before making any institution-grade calibration claims.

## Suggested first batch themes

1. Near-term geopolitical authorization / non-authorization events
2. Observable infrastructure or policy triggers with clear public primary records
3. Market or rate decisions with official announcement windows

## Rules

- No silent overwrites.
- No post-hoc probability changes after the horizon opens.
- Prefer SRC-T1 / SRC-T2 resolution sources.
- Record both correct outcomes reached through poor reasoning and sound reasoning defeated by irreducible uncertainty.
